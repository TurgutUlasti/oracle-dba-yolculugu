# Oracle DBA Yolculuğu 🚀

Bu repo, Computer Programming mezunu olarak Veritabanı Yöneticisi (DBA) kariyerine
geçiş sürecimde tamamladığım kurslardan edindiğim pratik örnekleri ve notları içerir.

BTK Akademi "Veritabanı Yöneticisi" kariyer yolunu takip ediyorum ve bu repo,
sürecin ilerleyişini şeffaf şekilde göstermek için düzenli olarak güncellenecek.

## 📚 İçerik

| Klasör | Konu | Durum |
|---|---|---|
| [01-tsql](./01-tsql) | T-SQL temelleri (DML, JOIN, aggregate, subquery, tarih fonksiyonları) | ✅ Tamamlandı |
| [02-plsql](./02-plsql) | PL/SQL (anonim blok, veri tipleri, %TYPE/%ROWTYPE, fonksiyon, exception handling) |✅ Tamamlandı |
| [03-oracle-dba](./03-oracle-dba) | Oracle DBA 1-2, kurulum notları (VirtualBox + Oracle Linux) | 🔄 Devam ediyor |
| [04-buyuk-veri](./04-buyuk-veri) | Büyük Veriye Giriş, Büyük Veri | ⏳ Planlanan |
| [05-veritabani-guvenligi](./05-veritabani-guvenligi) | Veritabanına Saldırı, Veritabanı Güvenliği, Temel Siber Güvenlik | ⏳ Planlanan |

## 🎯 Hedef

Aralık 2026'ya kadar yukarıdaki tüm kurs sürecini tamamlayıp, Oracle odaklı
bir DBA pozisyonuna geçiş yapmak.

## 🛠️ Kullanılan Teknolojiler

- Oracle Database (VirtualBox + Oracle Linux üzerinde kurulum)
- SQL Server (T-SQL)
- PL/SQL
