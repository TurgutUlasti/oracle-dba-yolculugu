# T-SQL

Bu klasör, T-SQL (SQL Server) kursu sürecinde yazdığım pratik sorguları içerir.
Kurs tamamlandı ✅ — Oracle PL/SQL'e geçiş yapıldı.

## Dosyalar

| Dosya | Konu |
|---|---|
| `where-distinct-orderby-top.sql` | WHERE, AND/OR, DISTINCT, ORDER BY, TOP kullanımı |
| `dml-temel-sorgular.sql` | Temel SELECT/INSERT/UPDATE/TRUNCATE (DML) örnekleri |
| `aggregate_fonksiyonlari.sql` | MIN/MAX/COUNT/SUM/AVG, GROUP BY, HAVING ile şehir bazlı satış analizi |
| `subquery-ornekleri.sql` | Alt sorgu (subquery) kullanımı, ürün fiyat istatistikleri |
| `join-siparis-detay.sql` | Çoklu tablo INNER JOIN ile sipariş detay raporu |
| `join-aylik-siparis.sql` | JOIN + CASE WHEN ile aylık sipariş raporu |
| `odeme-turu-aylik.sql` | CASE WHEN ile ödeme türü ve aylık ödeme analizi |
| `teslimat-suresi-analizi.sql` | DATEDIFF ile ortalama/min/max teslimat süresi analizi |

## Öne Çıkan Konular

- WHERE / AND / OR / IN / BETWEEN
- DISTINCT, ORDER BY, TOP
- Aggregate fonksiyonlar (MIN, MAX, COUNT, SUM, AVG) + GROUP BY / HAVING
- Subquery (alt sorgu) kullanımı
- Çoklu tablo JOIN (INNER JOIN)
- CASE WHEN ile koşullu sütun üretimi
- Tarih fonksiyonları (DATEPART, DATEDIFF, CONVERT)
