# PL/SQL

Bu klasör, PL/SQL kursu sürecinde yazdığım pratik örnekleri içerir. 🔄 Devam ediyor.

## Dosyalar

| Dosya | Konu |
|---|---|
| `anonim_block_gun_ismi.sql` | DECLARE/BEGIN/END anonim blok temelleri (TO_CHAR ile gün ismi) |
| `char-vs-varchar2.sql` | CHAR ve VARCHAR2 veri tiplerinin farkı |
| `type-rowtype-kullanimi.sql` | %TYPE ve %ROWTYPE ile dinamik değişken/kayıt tanımlama |
| `binary-integer-overflow.sql` | BINARY_INTEGER, PLS_INTEGER, NUMBER tipleri ve overflow (aşırı yükleme) |
| `fonksiyon-bolum-adi.sql` | CREATE FUNCTION ile bölüm adını dönen fonksiyon örneği |
| `exception-handling.sql` | Exception handling (hata yönetimi), yukarıdaki fonksiyonun kullanımı |

## Öne Çıkan Konular

- Anonim blok yapısı (DECLARE / BEGIN / END)
- Veri tipleri: CHAR, VARCHAR2, NUMBER, BINARY_INTEGER, PLS_INTEGER
- %TYPE ve %ROWTYPE
- Fonksiyon oluşturma (CREATE OR REPLACE FUNCTION)
- Exception handling (SQLERRM, WHEN ... THEN)

## Planlanan Konular

- Cursor kullanımı
- Stored procedure
- DML / DDL / DCL örnekleri
- BLOB işlemleri
- Transaction management
